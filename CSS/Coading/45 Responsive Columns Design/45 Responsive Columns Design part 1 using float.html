HTML

create the structure of a website. It is used to add elements such as headings, paragraphs, images, links, tables, forms, buttons, and lists to a web page. HTML uses tags such as html, head, body, h1, and p to organize content.

CSS

CSS (Cascading Style Sheets) is used to design and style HTML webpages. It controls the appearance of elements such as colors, fonts, sizes, spacing, borders, backgrounds, and layouts.

JavaScript

JavaScript is a programming language commonly used to make websites interactive and dynamic. With JavaScript, developers can create features such as dropdown menus.

Python

Python is a popular, high-level programming language known for its simple and readable syntax. It is used in many areas, including web development, artificial intelligence.
